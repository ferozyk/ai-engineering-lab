# Visual Reporting Standards

## Tools

Matplotlib is the default. Use Plotly only when interactivity adds meaningful value.

## Chart types

| Purpose | Chart |
|---|---|
| Compare average latency | Bar chart |
| Latency distribution | Box plot |
| Token or cost comparison | Grouped bar chart |
| Concurrency and throughput | Line chart |
| Multi-metric overview | Radar chart, only when the normalisation and its limitations are explained |

Architecture and execution flows use Mermaid diagrams.

## Every chart must

- [ ] Have a descriptive title
- [ ] Label axes
- [ ] Include units
- [ ] Have a legend where necessary
- [ ] Clearly identify the compared implementations
- [ ] Include relevant benchmark context
- [ ] Avoid misleading scales
- [ ] Be generated from actual benchmark data

## Formats and locations

- PNG for LinkedIn-ready visuals; SVG where appropriate for documentation.
- Original charts: `experiments/<experiment-name>/results/charts/`.
- LinkedIn-ready assets: `experiments/<experiment-name>/linkedin/visual-assets/`.

## Generation

Charts are generated by code from benchmark data and are never hand-edited or populated with invented values. Chart utilities will be added to `ai_lab` when the first experiment needs them.

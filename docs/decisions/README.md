# Architecture Decision Records

An ADR is a short document capturing a significant technical decision, its context and its consequences. ADRs are numbered sequentially and are not rewritten; a later ADR supersedes an earlier one.

To add one, copy [0000-template.md](0000-template.md) to the next free number (for example `0003-short-title.md`) and fill it in.

# visual-assets

LinkedIn-ready graphics.

- Landscape: 1200 x 627 px

Each asset should include:

- [ ] Experiment title
- [ ] Compared approaches
- [ ] Measured findings
- [ ] One takeaway
- [ ] Repository link

Assets are generated from data in `results/`, never from invented values. Original charts stay in `results/charts/`.
